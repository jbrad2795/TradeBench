Watch one negotiation happen.

A replay of a single recorded run - the public table on one side, the two consultation rooms below it, staying sealed from each other for the whole four rounds.

This page replays a run that has already happened, from a static log file. It does not call any model API. There is no live harness behind it - that would put an open spend surface on the public internet, and the recorded run shows the same thing.

Watch the two lower panels. Nothing crosses between them for the whole run - that is lib/channels.js doing its job, and it is asserted by test rather than left to care. The capital seats can read the table but cannot speak into it. Private rationale is expandable here for evaluation; no seat could ever see another's. The full log for this run is in Reproduce it.

TradeBench - an evaluation benchmark and harness for trade negotiations.
